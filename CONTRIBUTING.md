# Contributing

Requirements: Bun 1.3.14 or newer and Node.js 22.23.4 or newer (the minimum for current Astro 7 releases).

```sh
bun install --frozen-lockfile
bun run check
bun run test:integration
```

Keep changes focused and add a regression test for behavior changes. Changes to supported Astro or Bun versions must update the compatibility matrix and README.

By participating, you agree to follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
